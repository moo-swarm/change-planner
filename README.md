# Change Planner

An interactive change management planning tool based on Jurgen Appelo's "How to Change the World" framework — plan change initiatives across all 4 facets with guided prompts and action tracking.

Part of the [Agile Tools](https://github.com/bthos) suite built on Management 3.0 and ICAgile source materials.

## Stack
React 18 · TypeScript · Vite · Tailwind CSS · react-i18next (EN/RU)

## Development
```bash
npm install
npm run dev
```

## Deploy
GitHub Pages via GitHub Actions on push to `main`.
